## 4.10.0 (2020-05-15)

- Add functions for cyclotomic algebras: `ReducingCyclotomicAlgebra`,
  `CyclotomicExtensionGenerator`, `KillingCocycle`, `AntiSymMatUpMat` and
  `GlobalSplittingOfCyclotomicAlgebra`
- Add character descent functions: `CharacterDescent`,
  `GlobalCharacterDescent`, `GaloisRepsOfCharacters`,
  `SimpleComponentByCharacterDescent` and
  `WedderburnDecompositionByCharacterDescent`
- Fix `DecomposeCyclotomicAlgebra` returning cyclotomic algebras with zero
  factor set for some inputs, and make it fail less often
- Fix `SchurIndexByCharacter` failing for a character given by its position,
  and fix `DefiningCharacterOfCyclotomicAlgebra` (#65)
- Make `LocalIndicesOfRationalSymbolAlgebra` return `fail` unless both
  arguments are -1 or positive primes
